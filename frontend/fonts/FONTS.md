# Fontes

Todas as fontes são self-hosted em WOFF2 e licenciadas sob a **SIL Open Font License 1.1**. Os textos completos das licenças estão nesta pasta.

| Família | Arquivos | Licença | Origem |
| --- | --- | --- | --- |
| Instrument Serif | `instrument-serif-regular.woff2`, `instrument-serif-italic.woff2` | OFL 1.1 | Google Fonts / Instrument Serif Project Authors |
| Literata | `literata-regular.woff2` (variável), `literata-italic.woff2` | OFL 1.1 | Google Fonts / Literata Project Authors |
| Schibsted Grotesk | `schibsted-grotesk-regular.woff2` (variável), `schibsted-grotesk-italic.woff2` | OFL 1.1 | Google Fonts / Schibsted-Grotesk Project Authors |

- `instrument-serif` não tem eixo variável; use apenas o peso 400.
- `literata` e `schibsted-grotesk` são variáveis; os arquivos cobrem o intervalo de pesos usado pelo sistema.
- Se uma fonte falhar, o fallback declarado em `tokens.css` mantém a leitura (Georgia / Times / Helvetica).
